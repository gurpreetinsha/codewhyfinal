CODEWHY turns a repository into an explorable engineering workspace. Start with the architecture and repository health, then jump directly into focused tools for security, dependency risk, investigations, code questions and change review. Each tool has its own dedicated workspace so the Overview stays a useful launchpad instead of becoming one endless dashboard.

01 · Understand

Code graph

Explore files, functions, classes and detected relationships to understand how the codebase is connected.

02 · Prioritise

Technical debt

Review maintainability signals such as oversized files, long functions and TODO/FIXME markers.

03 · Ask

Ask CODEWHY

Ask natural-language questions about behaviour and get answers grounded in retrieved source evidence.

04 · Protect

Security center

Run Sentinel checks for exposed secrets, risky patterns, dependency advisories and possible attack paths.

05 · Investigate

Autonomous investigator

Trace a question through related files and dependencies, with an evidence trail for the result.

06 · Review

PR risk reviewer

Inspect changed files, dependency impact and static risk signals before a pull request is merged.

07 · Predict

Change simulator

Run a static pre-merge review of a proposed diff to surface likely impact and security concerns.

08 · Learn

History & reports

Revisit saved investigations, security scan history and exportable repository reports.

09 · Audit

Commit history checker

Inspect recent repository commits, authors, timestamps and file-level change summaries. Open any commit on GitHub for the full diff.
